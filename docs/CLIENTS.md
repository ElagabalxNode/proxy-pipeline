# Подключение клиентов через `pipelinectl links`

Этот файл объясняет, как брать результат `pipelinectl links` и импортировать его в Shadowrocket или любой другой клиент, который понимает современные ссылки `vless://` и `ss://`.

## Что выдает `pipelinectl links`

Запустите:

```bash
pipelinectl links
```

Команда печатает ссылки и при `--export` сохраняет их в `.client-links`.

Обычно вы увидите такие профили:

- `Direct-VLESS-...`
- `Direct-SS2022-...`
- `Bridge-VLESS-...`
- `Bridge-SS2022-...`

Что это значит:

- `Direct-*` подключает клиента напрямую к Exit-ноду. Это удобно для проверки.
- `Bridge-*` подключает клиента через RU Bridge, а затем в Exit. Это основной рабочий маршрут, если Bridge включен.

Рекомендуемый порядок:

1. Сначала импортируйте `Direct-VLESS` и убедитесь, что он подключается.
2. Потом импортируйте `Bridge-VLESS`.
3. `SS2022` оставьте как запасной вариант.

## Какую ссылку выбирать

Основной вариант:

- `Bridge-VLESS-*` для обычной работы

Для диагностики:

- `Direct-VLESS-*`

Запасные профили:

- `Bridge-SS2022-*`
- `Direct-SS2022-*`

Замечания:

- `VLESS Reality` обычно лучше всего подходит как основной профиль.
- `SS-2022` удобен как fallback, если у клиента проблемы с Reality.
- Не все клиенты поддерживают `2022-blake3-aes-128-gcm`. Если `ss://` не импортируется, используйте `vless://`.

## Shadowrocket

Shadowrocket умеет импортировать одиночные `vless://` и `ss://` ссылки из буфера обмена или через кнопку `+`. Общая справка по импорту: [Shadowrocket Guide 2026](https://clashx.tech/en/shadowrocket-guide) и [How to Add Servers | Shadowrocket Help](https://shadowrocketvpn.app/help/servers/add).

### Самый быстрый способ

1. Запустите `pipelinectl links`.
2. Скопируйте одну полную строку `vless://...` или `ss://...`.
3. Откройте Shadowrocket.
4. Нажмите `+`.
5. Вставьте ссылку.
6. Сохраните профиль.
7. Выберите его и подключитесь.

Shadowrocket часто сам предлагает импорт из буфера обмена. Если этого не произошло, добавьте профиль вручную через `+` и вставьте URI.

### Импорт через QR-код

Если нужен QR:

```bash
pipelinectl links --export --qr
```

После этого в корне репозитория появится каталог:

```text
.client-links-qr
```

В нем будут PNG-файлы:

- `direct_vless.png`
- `direct_shadowsocks.png`
- `bridge_vless.png`
- `bridge_shadowsocks.png`

В Shadowrocket:

1. Откройте приложение.
2. Нажмите `+`.
3. Выберите сканирование QR-кода.
4. Покажите приложению нужный PNG с экрана или импортируйте его как изображение, если клиент это поддерживает.
5. Сохраните профиль.

### Какие профили лучше импортировать в Shadowrocket

Рекомендуемый порядок:

1. `Bridge-VLESS-*`
2. `Direct-VLESS-*`
3. `Bridge-SS2022-*`
4. `Direct-SS2022-*`

Лучше сразу переименовать их в понятные названия.

Например:

- `proxy-bridge-vless`
- `proxy-direct-vless`
- `proxy-bridge-ss`
- `proxy-direct-ss`

## Другие клиенты

Большинство современных клиентов умеют импортировать такие ссылки напрямую.

Примеры:

- `v2rayN`
- `Nekobox`
- `Hiddify`
- `Streisand`
- `FoXray`
- клиенты на базе `sing-box`

Обычный порядок действий:

1. Скопируйте полную строку `vless://...` или `ss://...`.
2. В клиенте выберите `Import from clipboard`, `Import URI`, `Add from URL` или `Scan QR`.
3. Вставьте ссылку или отсканируйте QR.
4. Сохраните профиль.
5. Подключитесь и проверьте работу.

Если клиент не умеет автоимпорт, используйте ручной ввод.

## Поля для ручного ввода

### VLESS Reality

Берите значения из `vless://...` ссылки.

Соответствие полей:

- Адрес: хост после `@`
- Порт: порт после `:`
- UUID: значение до `@`
- Transport: `tcp`
- Security: `reality`
- Flow: `xtls-rprx-vision`
- SNI: значение `sni=...`
- Public key: значение `pbk=...`
- Short ID: значение `sid=...`
- Fingerprint: `fp=chrome`

Для этого проекта ручной ввод обычно не нужен: ссылка уже полностью готова к импорту.

### Shadowsocks 2022

Берите значения из `ss://...` ссылки.

Важно:

- Метод и пароль находятся в base64-части до `@`
- Адрес сервера находится после `@`
- Порт находится после `:`

Если у клиента есть действие вроде `Import SS URL`, лучше использовать его.

## Как проверить, что профиль рабочий

После импорта:

1. Подключитесь к профилю.
2. Откройте сайт через клиента.
3. Если клиент умеет, запустите тест задержки.
4. Если профиль через Bridge не работает, проверьте соответствующий Direct-профиль.

Хороший порядок диагностики:

1. `Direct-VLESS`
2. `Bridge-VLESS`
3. `Direct-SS2022`
4. `Bridge-SS2022`

## Частые ошибки

- Копируется комментарий вроде `# DIRECT (test)`, а не сама URI-строка
- Вместе со ссылкой копируются лишние переносы строк
- Пользователь пытается открыть `vless://` или `ss://` в браузере, а не импортировать в клиент
- Используется старый клиент без поддержки Reality или SS-2022
- Ожидание, что `pipelinectl links` выдаст subscription URL, хотя он выдает именно одиночные URI профилей

## Нормальный workflow

```bash
pipelinectl configure
pipelinectl validate
pipelinectl links --export --qr
```

После этого:

1. Импортируйте `Bridge-VLESS` в основной клиент.
2. Импортируйте `Direct-VLESS` как резервный профиль.
3. Импортируйте один или оба `SS2022` профиля как fallback.

## Где лежат ссылки и QR

Текстовые ссылки:

```text
.client-links
```

QR-коды:

```text
.client-links-qr/
```

Если нужен только текст без QR:

```bash
pipelinectl links --export
```

Если нужен текст и QR:

```bash
pipelinectl links --export --qr
```
